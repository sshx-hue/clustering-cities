# Кластеризация городов тремя методами

Лабораторные 1–3 по курсу «Анализ данных на Python», магистратура ИТМО. Одни и те же 46 городов разбиваю методом Уорда, K-means и DBSCAN и сравниваю, что нашёл каждый.

## Данные

`Economics_of_Cities.csv`, 48 городов и три признака. `Work` это рабочие часы в год, `Price` индекс цен, `Salary` индекс зарплат (у Цюриха 100).

У Каира и Джакарты вместо двух признаков из трёх стоят заглушки −9999. Медиану подставлять не стал, это значило бы выдумать городу две трети данных, поэтому оба города удалил. Гонконг по часам выходит за межквартильный размах, но значение настоящее, его оставил.

## Стандартизация

Без неё `Work` забирает 96.6% расстояния, потому что часы измеряются тысячами, а индексы десятками. Кластеры тогда собираются по часам, Цюрих попадает в один кластер с Найроби, силуэт 0.05–0.13. После стандартизации каждый признак даёт треть расстояния, дальше работаю только со стандартизованными данными.

## Что получилось

| Метод | Ноутбук | Кластеров |
|---|---|---|
| Уорд | `ierarh_clustering.ipynb` | 4, силуэт 0.355 |
| K-means | `kmeans_clustering.ipynb` | 4, силуэт 0.340 |
| DBSCAN | `dbscan_clustering.ipynb` | 2 и 9 точек шума |

Число кластеров выбирал по дендрограмме, локтю, силуэту, Calinski-Harabasz и Davies-Bouldin. Все они показывают на 2 кластера, богатые и бедные города, потому что цены и зарплаты сильно связаны. Я взял 4. Это те же 2, только каждый поделён пополам, и их проще описать.

- Самые дорогие (6). Цюрих, Женева, Токио, Осло, Стокгольм, Хельсинки.
- Развитые (19). Лондон, Париж, Нью-Йорк, Франкфурт, Сидней и другие.
- Небогатые с обычным рабочим годом, около 1800 часов (7).
- Небогатые, которые работают дольше всех, около 2080 часов (14). Гонконг, Сингапур, Тайбэй, Манила, Богота и другие.

Уорд и K-means совпали на 40 городах из 46. Спорят они только о пограничных. Копенгаген и Мадрид по зарплате находятся между самыми дорогими и развитыми, а Буэнос-Айрес, Йоханнесбург, Мехико и Найроби по часам между двумя небогатыми группами.

DBSCAN без шума полностью совпал с Уордом и K-means при 2 кластерах (ARI = 1). Значит, деление на богатых и бедных устойчивое, его находят три метода с разной логикой. Среди 9 точек шума все 6 самых богатых городов, Гонконг и Тайбэй. Богатые города далеко друг от друга и плотной группы не образуют, у Уорда этот кластер тоже был самым рыхлым. Гонконг и Тайбэй выделяются очень длинным рабочим годом.

## Как запустить

```bash
pip install -r requirements.txt

```

Ноутбуки идут по порядку, Уорд, потом K-means, потом DBSCAN.
